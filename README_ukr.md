## 📌 Про проєкт

ShopSphere — глобальний онлайн-маркетплейс, що продає товари 7 категорій у 5 регіонах світу. У проєкті пройдено повний аналітичний цикл: від сирих даних у 5 таблицях до дашборду для ради директорів і стратегічних рекомендацій для CEO.

CEO поставила п'ять запитань:
- Куди йдуть маркетингові гроші й чи ефективно?
- Хто найцінніші клієнти?
- Які категорії справді прибуткові, а які лише створюють ілюзію обсягу?
- Які регіони — майбутнє компанії?
- Чи спрацював експеримент на checkout?

Цей репозиторій — послідовна відповідь на всі п'ять питань, підкріплена даними.

## Хід роботи

### 0. Перевірка якості даних

Перед будь-якими розрахунками перевірено внутрішню узгодженість таблиць — чи можна довіряти цифрам.

**Перевірено 3 гіпотези:**

1. **`net_amount` = `gross_amount` − `discount_amount`?**
   Розбіжність знайдена у **3 269 замовленнях з ~11 тис.** (~30%). За основу для всіх подальших розрахунків взято поле **`net_amount`** як фактичну суму, яку реально сплатив клієнт.
2. **`line_total` = `quantity × unit_price`?**
   ✅ Розбіжностей не знайдено — калькуляція коректна.
3. **`discount_amount` = `gross_amount × discount_pct / 100`?**
   Розбіжність у **263 замовленнях з ~11 тис.** (~2,4%) — визнано несуттєвою.

📄 Повний код перевірки — [`Перевірка_баз_данних.docx`](./Перевірка_баз_данних.docx)

### 1. SQL: підготовка даних

П'ять запитів (JOIN, агрегації, підзапити), що стали основою для подальшої візуалізації та бізнес-кейсів:
1. Виручка по роках і регіонах
2. Топ-10 клієнтів за виручкою
3. Виручка, маржа та повернення по категоріях
4. Клієнти з витратами вище середнього (підзапит) — база для розрахунку топ-5%
5. ROI та ефективність маркетингових каналів

📄 Запити — папка [`SQL_query/`](./SQL_query)

### 2. Дашборд

Інтерактивний дашборд, зібраний як історія зверху вниз:
1. **KPI-картки** — виручка, замовлення, середній чек, % повернень
2. **Динаміка** — зростання виручки по кварталах, зростання ефективності по регіонах
3. **Продуктивність** — виручка/маржа/повернення по категоріях
4. **Маркетинг** — бюджет проти прибутку на долар

🔗 [Дивитись дашборд у Tableau Public](https://public.tableau.com/views/Abschlussproect/Dashboard1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

### 3. Кейс «Бюджет»: маркетинговий бюджет і ROI по каналах

Paid Search отримує найбільше бюджету (451 тис. $), але дає найнижчий ROI (+32,7%). Organic — найкращий ROI (+701%), але недофінансований. Порівняно ROI кампаній із довгостроковою цінністю клієнтів (LTV) — висновки не завжди збігаються. Дано рекомендацію з перерозподілу бюджету з урахуванням ризиків.

### 4. Кейс «Категорії»: обсяг ≠ прибуток

Electronics — «ілюзія обсягу» (57% виручки, 12% маржа, 16% повернень). Beauty — «прихований діамант» (55% маржа при частці виручки лише 4,6%). Окремо розглянуто, які регіони ростуть найшвидше (Southeast Asia, Middle East), а які стагнують (Europe, North America).

### 5. Кейс «Клієнти»: знижки та цінні клієнти

Знижка >20% не будує лояльність: клієнти зі знижкою роблять удвічі менше замовлень (2 проти 4). Топ-5% клієнтів дають 35% виручки — переважно через Influencer у Europe. Рекомендація — VIP-програма замість масових знижок.

### 6. A/B-тест: checkout

Класичний приклад парадоксу Сімпсона: загальний ефект варіанту B (+2%) ховає, що новим клієнтам він допомагає сильно (+13,1%), а постійним — майже ніяк (+1,2%). Розглянуто, як маркетинг міг би маніпулювати цими цифрами, і як їх подає чесний аналітик.
